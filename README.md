# OpenDNT

Анонимизирующая P2P-сеть, вдохновлённая I2P. Сообщения передаются через туннель из случайных неизвестных узлов-ретрансляторов, с многослойным шифрованием на каждом хопе.

Сеть проектируется в первую очередь **для использования на территории России** - с приоритетом на устойчивость к блокировкам и минимальную задержку, а не на максимальную теоретическую анонимность любой ценой.

## Цели проекта

- **Устойчивость к блокировкам** - в первую очередь к DPI-блокировкам (Роскомнадзор), за счёт обфускации трафика
- **Низкий пинг и высокая скорость** - сеть ориентирована на реальное использование внутри РФ, а не на глобальную анонимность как у Tor/I2P
- **Анонимность** - отправитель и получатель не знают, кто такие промежуточные узлы в туннеле, и наоборот

## Trade-off: скорость vs анонимность

Приоритет на низкую задержку означает осознанный компромисс:

- Релеи выбираются внутри РФ, а не по всему миру - это снижает пинг, но потенциально облегчает корреляционные атаки по времени для наблюдателя, контролирующего значительную часть сети внутри страны
- Количество хопов держится минимальным (~3), балансируя между анонимностью и скоростью

## Маршрутизация (onion routing, полный туннель)

- Клиент строит туннель через ~3 случайных узла
- Каждый узел в цепочке знает только предыдущий и следующий хоп - не весь путь
- Сообщение заворачивается в N слоёв шифрования (по числу узлов), каждый узел снимает свой слой
- Ответ возвращается через ту же цепочку туннеля

## Устойчивость к DPI-блокировкам

Одной анонимности недостаточно - трафик должен быть неотличим от обычного HTTPS-трафика, иначе DPI-системы блокируют по сигнатуре протокола. Планируется:

- Маскировка TLS/browser fingerprint под легитимный трафик
- Discovery через bridge-узлы (адреса не публикуются в открытом DHT, чтобы их нельзя было массово заблокировать)

## Маскировка и транспорт

- Маскировка: REALITY/uTLS
- Транспорт: TCP + TLS-обёртка

## Стек

- Язык: Go
- Discovery (план): Kademlia DHT
